# TRIAD UI段階実装報告

Phase：26 研究反映・接地感のある横座り

対象：ホーム画面 Hero Area（ヒバナの座り姿勢、接地、前後関係）

## 結論

YouTube上の複数ゲームのホーム／ロビー表現を比較し、TRIADの木舞台・和装・碁盤へ最も馴染む姿勢として「横座り」を採用した。片膝を大きく立てる旧案を廃止し、腰、折り畳んだ両脚、広がる裾、支える手で同一の接地面を示した。碁盤を手前へ重ねることで下半身を自然に隠し、宙に浮いて見える問題を解消した。

## 参考にしたゲーム映像と抽出した共通原則

- Blue Archive Memorial Lobby：キャラクターの重心と背景内の支持物を一致させ、画面全体を一枚の情景として見せる。
- NIKKE Lobby／立ち絵演出：座り姿勢では腰の位置、膝の高さ、支持物との接触を明確にし、手前UIとの重なりで奥行きを作る。
- Azur Lane Secretary／Live2D：衣装や髪を背景の光と色へ馴染ませつつ、顔と上半身を主要な視線誘導点として残す。

個別作品の絵を複製せず、上記の共通する構図原則だけをTRIAD固有のヒバナへ適用した。

- Figma：今回未使用

## 今回実装したもの

- `HibanaSeated-v4.png` を新規追加。
- 顔、髪、髪飾り、赤白黒金の衣装、炎の黒珠というヒバナの識別要素を維持。
- 両脚を一方向へ畳む横座りへ変更。
- 腰を低くし、片手を舞台へ着け、裾を横方向へ広げて接地を明示。
- 右端を含む全身余白を確保し、衣装切れを解消。
- 接地影を横長へ変更し、腰と裾の下へ配置。
- 碁盤をキャラクターより手前に維持し、脚部を自然に隠す。
- キャラクター画像は縦横比を保持し、4096px上限、RGBA32、非圧縮、ミップマップ無効で取り込み。

## 生成プロンプトの要点

既存v3を参照し、人物同一性と衣装意匠を保持したまま、木舞台へ接地する横座り、支える手、低い膝、面に沿って広がる裾、右端を含む全身余白、透明背景、高精細ゲーム用キーアートを指定した。
