# TRIAD UI段階実装報告

Phase：25

対象：キャラクター右端補完、接地、碁盤方向、Unity表示画質の原因究明と修正

## 結論

Unity表示で元絵より画質が落ちた主因は、テクスチャ圧縮だけではなく、キャラクター画像を元の2:3比率からほぼ正方形へ非等方拡大していたことだった。これにWindows向けBC7圧縮、背景の標準圧縮、390×844への縮小再サンプリングが重なり、髪、金装飾、桜、衣装模様が甘く見えていた。

## 今回使用したツール

- Unity Personal（無料）
- OpenAI組み込み画像生成（キャラクター右側補完、3/4方向の碁盤素材）
- Figma：未使用
- Blender：未使用
- Rive：既存導入状態。今回の変更には未使用

## 今回実装したもの

- キャラクターの顔、ポーズ、衣装を維持しつつ、右側の髪・袖・裾を補完した透明素材へ更新
- キャラクターの元画像比率2:3をUnity上でも固定
- キャラクターを少し下げ、裾と座面を木の舞台へ接続
- 接地専用の柔らかい影を追加
- 碁盤のRectTransform回転を0度へ変更
- 碁盤は素材内部の3/4パースだけで斜め方向を表現
- キャラクター、背景、碁盤、CTA、サブメニュー画像を無圧縮へ変更
- 最大取り込みサイズを4096pxへ変更
- ミップマップ、ストリーミングミップマップ、NPOT強制縮小を無効化
- Canvasを390×844基準のピクセルパーフェクト表示へ変更

## 画質低下の原因

1. キャラクターの非等方拡大
   - 元画像：1024×1536、縦横比2:3
   - 旧表示枠：342×364付近、ほぼ正方形
   - RawImageが枠全体へ伸長され、横方向へ大きく歪んでいた

2. ブロック圧縮
   - キャラクターはWindows向けBC7
   - 背景と各画像は標準圧縮
   - 細い髪、金線、花びら、格子線で圧縮劣化が見えやすかった

3. 多段階リサイズ
   - 元画像を歪ませて拡大した後、390×844へ再縮小していた
   - 輪郭と細線が二重に再サンプリングされていた

4. 元キャラクター素材の右端切れ
   - 元素材自体が右側の髪と衣装を画像端で切っていた
   - Unityのマスクと拡大によって切れが強調されていた
