## 輝度比較

画面全体の知覚輝度を比較した。

| 指標 | Phase 22 | Phase 23 | 参考画像 |
|---|---:|---:|---:|
| 平均 | 37.68 | 54.58 | 70.53 |
| 25%点 | 12.44 | 21.00 | 21.31 |
| 中央値 | 18.96 | 46.14 | 50.69 |
| 75%点 | 37.49 | 64.93 | 107.08 |
| 90%点 | 100.05 | 121.09 | 167.45 |

暗部の基準（25%点）は参考画像とほぼ一致し、中央値も近づいた。参考画像の上位輝度がさらに高い主因は、提灯、月、桜、金装飾などの強い発光ハイライトである。画面全体をさらに白くすると夜景の深みと文字コントラストが損なわれるため、次の改善では素材ごとのハイライト追加が適切。
