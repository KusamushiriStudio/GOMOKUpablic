# TRIAD 開発番号表

この番号表を、今後の作業指示・進捗報告・コミットの共通基準とする。

## Home Phase 1 — Header

1. 現行ホーム画面と既存機能を棚卸しする。
2. Figma無料プランの利用状態を確認する。
3. UI Design Systemの基礎トークンを定義する。
4. Headerの画面構成をFigmaで設計する。
5. TRIADロゴを独立パーツ化する。
6. 通貨表示を独立コンポーネント化する。
7. メールボタンを独立コンポーネント化する。
8. 通知ボタンと未読バッジを独立コンポーネント化する。
9. HeaderをUnity uGUIへ実装する。
10. 実表示・既存機能・iPhone縦画面・スクリーンショットを検証する。
11. Headerの確認結果を確定する。

## Home Phase 2 — Player Status

12. Player Statusの既存データ仕様を整理する。
13. Player StatusをFigma無料版で設計する。
14. アイコン・名前・Lv・EXP・段位・称号を独立要素化する。
15. Player StatusをUnity uGUIへ実装する。
16. 実プレイヤーデータを表示へ接続する。
17. 実表示・既存機能・iPhone縦画面・スクリーンショットを検証し、Phase単位でコミットする。

## Home Phase 3 — Hero Area

18. Hero AreaをFigma無料版で設計する。
19. 背景・ヒバナ・キャラクター情報・左ショートカットを独立要素化する。
20. キャラクター画像の解像度・差し替え方法・表示規則を確定する。
21. Hero AreaをUnity uGUIへ実装する。
22. 使用キャラクター変更を表示へ接続する。
23. 実表示・既存機能・iPhone縦画面・スクリーンショットを検証し、Phase単位でコミットする。

## Home Phase 4 — Story Banner

24. Story BannerをFigma無料版で設計する。
25. 新章・告知・カルーセル状態を設計する。
26. Story BannerをUnity uGUIへ実装する。
27. 物語進行・解放状態を表示へ接続する。
28. 実表示・既存機能・iPhone縦画面・スクリーンショットを検証し、Phase単位でコミットする。

## Home Phase 5 — Main CTA

29. Main CTAをFigma無料版で設計する。
30. 対戦・物語ボタンの通常・押下・無効状態を設計する。
31. Main CTAをUnity uGUIへ実装し、既存の対戦・物語遷移へ接続する。
32. 誤タップ・二重タップ・戻る操作を検証する。
33. 実表示・既存機能・iPhone縦画面・スクリーンショットを検証し、Phase単位でコミットする。

## 運用ルール

- 番号を飛ばさず、各PhaseをFigma→Unity→実表示→テスト→スクリーンショット→コミットの順で完了する。
- 33番の完了まではPhase 6以降へ進まない。
- Figma、Rive、Blenderその他の有料契約は自動で行わない。
- UI画像を1枚の背景として貼らず、状態変更できる独立パーツとして実装する。
- 既存ロジックを保護し、UI層とは表示契約を介して接続する。
